十一、常见错误速查

  • fetch first：远程仓库有本地没有的提交。先 git fetch、检查日志，再决定合并方式，不要未经确认强推。
  • embedded git repository：主题被错误地当作普通目录加入，应使用 Git submodule。
  • PicGo 409 Conflict：目标路径与已有文件或目录冲突。本项目最终使用 img/，而不是冲突的 images/。
  • PicGo 401 Bad credentials：检查 Token 是否过期、是否有多余空格、是否授权正确仓库，以及 Contents 是否为 Read and write。
  • jsDelivr 暂时打不开：先使用同一路径的 Raw 地址，等待 CDN 刷新。

总结

这次流程最终形成了清晰分工：Hexo 生成静态博客，Keep 负责主题，GitHub Pages 负责发布，PicGo 负责上传图片，GitHub 仓库存储图片，jsDelivr 提供 CDN 地址。

真正影响成功率的细节是：确认网络和代理、主题使用 submodule、不要覆盖已有远程仓库、确认图床路径实际是目录、Token 只保存在本机，以及每次发布前执行完整构建。
